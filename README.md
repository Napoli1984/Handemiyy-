# Handemiyy

Giochi con le foto di Hande: **Memory** (con la caccia al tesoro), **Ultima carta** e **Puzzle**. In italiano e in turco.

Gioca qui: https://napoli1984.github.io/Handemiyy-/

Per Memory e Ultima carta si può scegliere tra sei **modelli di carte** (Classico, Polaroid, Cipria, Notte, Nazar e Oro, il premio della caccia al tesoro).

Memory e Ultima carta si possono giocare anche **online con gli amici** (da 2 a 4, ognuno sul suo telefono): chi crea la stanza manda il link agli altri. I messaggi passano da un servizio MQTT pubblico e gratuito.

Fan game senza scopo di lucro: le foto appartengono ai rispettivi autori.
